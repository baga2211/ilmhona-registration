# Ilmhona — Опросник для регистрации на курсы

Мини-приложение на Next.js. Заявки автоматически попадают в Google Таблицу и раскладываются по вкладкам: **каждый курс + месяц (поток) = отдельный лист**.

Например: студент выбрал «Python lvl 1» в июле 2026 → его данные появятся:
- в листе **«Все заявки»** (общий список);
- в листе **«Python lvl 1 — 07.2026»** (только этот курс и этот поток).

В августе автоматически создастся новый лист «Python lvl 1 — 08.2026» — так потоки не смешиваются.

---

## Шаг 1. Запуск проекта

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Шаг 2. Подключение Google Таблицы

1. Создайте новую таблицу на [sheets.google.com](https://sheets.google.com).
2. В меню: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте код из файла `google-apps-script.gs` (лежит в корне проекта). Сохраните.
4. Нажмите **Развернуть → Новое развёртывание**:
   - Тип: **Веб-приложение**
   - «Выполнять от имени»: **Я**
   - «У кого есть доступ»: **Все**
5. Google попросит разрешения — подтвердите.
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

## Шаг 3. Переменная окружения

Создайте в корне проекта файл `.env.local`:

```
GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/ВАШ_ID/exec
```

Перезапустите `npm run dev` — готово. Отправьте тестовую заявку и проверьте таблицу.

## Деплой

Проще всего — [Vercel](https://vercel.com): импортируйте репозиторий и добавьте переменную `GOOGLE_SCRIPT_URL` в настройках проекта (Settings → Environment Variables).

## Как поменять список курсов

Файл `app/page.js`, массив `COURSES` в самом верху — просто добавьте или удалите строки.

## Структура

```
app/
  page.js            — форма (дизайн как на макете)
  globals.css        — стили
  api/submit/route.js — API: пересылает заявку в Google Script
google-apps-script.gs — код для Google Таблицы
```
